# CRAFT_SHOPPIFY API
1. Clonar proyecto
2. ``` pnpm install ```
3. Clonar el archvio ```.env.template``` y renombrar a ``` .env ```
4. Cambiar las variables de entorno
5. Levantar la base de datos 
```
docker-compose up -d
```
6. Ejecutar SEED
``` http://localhost:3000/api/seed ```

7. Levantar : ``` pnpm start:dev ```
